# Future ideas / Vormerkungen

## Current next steps

- Prepared, unreleased 1.2.0: global avatar/token source selection (avatar default); carousel displayed only after combat starts by default.
- Later: per-combatant source overrides and special highlights configured in the regular Combat Tracker before combat starts.
- Later: GM button to temporarily insert a legendary-action portrait, then return to the unchanged normal turn/initiative state.
- RPG Suite integration remains future work.

## Nächste Schritte

- Vorbereitet, noch unveröffentlicht in 1.2.0: weltweite Avatar-/Token-Bildauswahl (Standard Avatar); Carousel standardmäßig erst nach Kampfstart sichtbar.
- Später: Bildquelle pro Teilnehmer und besondere Hervorhebung über den normalen Combat-Reiter vor Kampfstart.
- Später: SL-Button zum Einschieben einer legendären Aktion mit temporärer Porträtanzeige, danach Rückkehr zum unveränderten regulären Zug und zur Initiative-Reihenfolge.
- RPG-Suite-Integration bleibt vorgemerkt.

These are plans, not features included in 1.0.0.

- Display-count settings were dropped by Daniel: retain all combatants, starting with the active one and then the remaining turn order.
- PC-only player view is prepared for unreleased 1.1.0, including an anonymous current NPC-turn placeholder and next visible PC.
- Optional, switchable integration into RPG Suite while retaining standalone use.

Diese Punkte sind vorgemerkt, in 1.0.0 aber noch nicht umgesetzt:

- Die optionale SC-Ansicht ist für die noch unveröffentlichte 1.1.0 vorbereitet: anonymer Platzhalter beim NSC-Zug und nächster sichtbarer SC.
- Spätere Integration als optional zuschaltbare Funktion der RPG Suite bei weiterhin eigenständiger Nutzung.
